# Contributing

Butler Interphone is developed issue-first.

## Workflow

1. Open or select a focused GitHub Issue.
2. Create a focused branch.
3. Keep one coherent feature per commit/PR.
4. Build and test before merge.
5. Merge to `main` only with appropriate evidence.

## Public-ready rule

Although the repository may be private during proving, every committed change must be safe for a future public release.

Do not commit:

- credentials or tokens;
- production/private endpoints;
- household-specific identifiers;
- personal data;
- raw biometric material;
- deployment-only configuration.

Use neutral examples and test fixtures.
