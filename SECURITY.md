# Security Policy

Butler Interphone is currently pre-release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting / security advisory workflow for this repository when available.

Do not open a public issue containing credentials, private endpoints, personal data, biometric material, or exploitable deployment details.

## Repository boundary

This repository must not contain production credentials, private household topology, household entity identifiers, personal data, raw voice samples, voiceprints, or biometric embeddings.

Runtime configuration and secrets belong outside source control.
