# Butler Interphone 0.1.0 — Ignition

First minor release of Butler Interphone and the Android endpoint of
Ignition Phase 1 / IGNITION-001.

## Included

- signed Android STABLE upgrade channel;
- text requests over Bifröst;
- runtime Butler directory and node manifest;
- explicit Butler targeting;
- deterministic sole-Butler default selection;
- Butler-first opening experience;
- themed product shell with secondary connection configuration;
- About/version/build information;
- LAN HTTP support for the current local Bifröst proving path.

## Ignition role

```text
Android -> Interphone 0.1.0 -> Bifröst 0.1.0 -> Midgard 0.1.0
        -> Butler Core 0.3.0
```

The exact compatible combination is recorded by IGNITION-001.

## Deferred

- Material 3 Expressive motion;
- automatic Bifröst pairing/device credentials;
- proactive notifications;
- structured interaction controls;
- polished voice UX.

## Boundary

No private endpoint, credential, household entity identifier or concrete
private-Butler implementation is part of the distributable client.
