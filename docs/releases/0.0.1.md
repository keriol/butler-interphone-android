# Butler Interphone 0.0.1

First alpha release checkpoint of Butler Interphone.

## Included

- signed Android STABLE upgrade channel;
- Android text client over Bifröst;
- Bifröst -> Midgard -> Butler Core / concrete Butler routing;
- explicit Butler targeting and runtime Butler directory;
- automatic default selection when exactly one Butler is available;
- live Bifröst node manifest / runtime explorer;
- Butler-first opening experience and themed product shell;
- secondary Connection configuration;
- About/version/build information;
- cleartext LAN HTTP support for the current local Bifröst proving path.

## Live proving

The 0.0.1 alpha baseline was accepted after live Android proving against the
private Keriol deployment. The complete path had already been proven through
Bifröst, Midgard, Asgard and Alfred with observable Home Assistant/media actions.

## Deliberately deferred

The following remain post-0.0.1 work:

- automatic Bifröst discovery and pairing;
- Material 3 Expressive motion;
- Butler profile imagery;
- structured confirmation/choice actions;
- proactive Android notifications;
- voice interaction.

## Boundary

This release contains no private endpoint, credential, household entity ID or
Alfred-specific implementation detail.
